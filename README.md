Every graphic on this page belongs to this repository. The portrait is generated<br>
from my profile photo by [`scripts/generate_portrait.py`](scripts/generate_portrait.py);<br>
the contribution, streak, language, and year graphics are drawn by<br>
[`scripts/update_profile.py`](scripts/update_profile.py) from GitHub's GraphQL API.

A [scheduled action](.github/workflows/refresh-profile.yml) refreshes the data once<br>
a day and commits only when pixels actually change. There are no hosted stat cards,<br>
tracking counters, or third-party image services to rate-limit or disappear.

The reveal animation lives inside each SVG using SMIL because GitHub strips scripts<br>
from profile READMEs. Portrait rows use explicit text lengths, so the character grid<br>
keeps its shape across operating systems without loading an external font.
